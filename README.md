# 🛒 Ecommerce End-to-End Data Analytics Project

## 📌 Project Overview

This project demonstrates a complete end-to-end data analytics workflow using SQL, Python, and Power BI.

The objective is to analyze e-commerce sales data, identify business trends, and generate actionable insights for decision-making.
